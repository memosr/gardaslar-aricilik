# Gardaşlar Arıcılık

1987'den beri yayla arıcılığı yapan Gardaşlar ailesinin web sitesi.

## Çalıştırma

```bash
npm install
npm run dev
```

Tarayıcıda http://localhost:3000 adresini aç.

## Aşamalar

1. ✅ Genel tasarım
2. 🟡 Gerçek içerik (ürün fotoğrafları, tarihçe, iletişim bilgileri)
3. ✅ Next.js projesi ve GitHub
   - `/magaza`: hasat takvimi, filtreli ürün listesi, arıcılık malzemeleri
4. ✅ Vercel yayını
5. ⬜ Sepet, ödeme ve sipariş sistemi

## Klasörler

- `app/` sayfa, düzen ve stiller
- `public/media/` video ve fotoğraflar
- `public/site.js` slider, sepet, parti sorgulama ve galeri etkileşimleri
